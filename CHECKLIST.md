# Чек-лист тестирования NordFlow Tasks

## 1. Авторизация и доступ

- [ ] Открыть `http://localhost:3000` — редирект на `/login`
- [ ] Открыть `http://localhost:3000/tasks` без авторизации — редирект на `/login`
- [ ] Войти с валидными данными (любой email `*@nordflow.ru`, пароль `password123`)
- [ ] Войти с неверным паролем — отображается ошибка
- [ ] Войти с пустыми полями — форма не отправляется
- [ ] Показать/скрыть пароль на странице входа
- [ ] Выйти из аккаунта — редирект на `/login`
- [ ] Проверить, что JWT токен сохраняется в cookie
- [ ] Обновить страницу — пользователь остаётся авторизованным

## 2. Боковое меню (Sidebar)

- [ ] Проверить отображение логотипа NordFlow
- [ ] Проверить отображение имени и фамилии текущего пользователя
- [ ] Проверить подсветку активного пункта меню
- [ ] Проверить подсветку при переходе на вложенные маршруты (`/projects/uuid`)
- [ ] Проверить скрытие мобильного меню при клике на ссылку
- [ ] Проверить видимость пункта "Пользователи" только для ADMIN

## 3. Главная страница (Dashboard)

- [ ] Проверить приветствие с именем пользователя
- [ ] Проверить отображение статистики (активные, просроченные, на неделе)
- [ ] Проверить отображение ближайших дедлайнов
- [ ] Проверить отображение последних обновлений (только задачи пользователя)
- [ ] Проверить отображение проектов
- [ ] Клик на проект/задачу — переход на соответствующую страницу

## 4. Задачи — список

- [ ] Открыть страницу `/tasks`
- [ ] Проверить отображение таблицы задач
- [ ] Проверить поиск по названию
- [ ] Проверить фильтр по статусу
- [ ] Проверить фильтр по проекту
- [ ] Пёреключение видов Список/Доска
- [ ] Клик на задачу в списке — открытие формы редактирования

## 5. Задачи — Kanban доска

- [ ] Переключить вид на "Доска"
- [ ] Проверить отображение 5 колонок (Бэклог, Запланировано, В работе, На проверке, Выполнено)
- [ ] Проверить количество задач в каждой колонке
- [ ] Перетащить задачу в другую колонку (drag & drop)
- [ ] Проверить, что статус задачи изменился после перетаскивания
- [ ] Проверить, что фильтры применяются и на доске

## 6. Создание задачи

- [ ] Нажать "Создать задачу"
- [ ] Проверить отображение модального окна
- [ ] Заполнить обязательные поля (название, проект, исполнитель, приоритет)
- [ ] Создать задачу — модальное окно закрывается, задача появляется в списке
- [ ] Проверить автоматическую генерацию идентификатора (название проекта + номер)
- [ ] Проверить уведомление исполнителю о назначении задачи

## 7. Редактирование задачи

- [ ] Кликнуть на задачу в списке или на доске
- [ ] Изменить название, описание, статус, приоритет, срок
- [ ] Сохранить изменения
- [ ] Проверить, что изменения отображаются в списке
- [ ] Проверить уведомление исполнителю об обновлении

## 8. Удаление задачи

- [ ] Удалить задачу через API (DELETE `/api/tasks`)
- [ ] Проверить, что комментарии и уведомления задачи тоже удалены

## 9. Проекты — список

- [ ] Открыть страницу `/projects`
- [ ] Проверить отображение карточек проектов
- [ ] Проверить фильтрацию по статусу (Все, Планирование, Активные, и т.д.)
- [ ] Проверить отображение руководителя проекта
- [ ] Клик на проект — переход на страницу проекта

## 10. Создание проекта

- [ ] Нажать "Создать проект" (доступно для ADMIN и PROJECT_LEAD)
- [ ] Заполнить название, описание, руководителя, статус, даты
- [ ] Сохранить — проект появляется в списке
- [ ] Проверить, что руководитель автоматически добавлен как LEAD-участник

## 11. Страница проекта

- [ ] Открыть страницу проекта
- [ ] Проверить 4 вкладки: Доска, Список задач, Участники, Информация

### Вкладка "Доска"
- [ ] Проверить Kanban доску проекта (только задачи этого проекта)
- [ ] Перетаскивание задач работает

### Вкладка "Список задач"
- [ ] Проверить таблицу задач проекта
- [ ] Клик на задачу — открытие формы редактирования

### Вкладка "Участники"
- [ ] Проверить список участников проекта
- [ ] Проверить отображение ролей (LEAD, MEMBER)

### Вкладка "Информация"
- [ ] Проверить отображение: название, описание, статус, руководитель
- [ ] Проверить отображение дат начала и окончания
- [ ] Проверить количество задач
- [ ] Нажать "Редактировать" — открытие формы редактирования проекта
- [ ] Изменить данные проекта и сохранить
- [ ] Удалить проект (только ADMIN) — подтверждение и удаление

## 12. Команда

- [ ] Открыть страницу `/team`
- [ ] Проверить отображение карточек участников
- [ ] Проверить отображение аватара (инициалы)
- [ ] Проверить отображение статистики (активных, просрочено)
- [ ] Проверить полоску нагрузки и её цвет (зелёный/оранжевый/красный)

## 13. Уведомления

- [ ] Открыть страницу `/notifications`
- [ ] Проверить отображение списка уведомлений
- [ ] Проверить иконки для разных типов уведомлений
- [ ] Клик на уведомление — переход на связанную задачу/проект
- [ ] Проверить, что уведомление помечается как прочитанное после клика
- [ ] Нажать "Отметить все как прочитанные"
- [ ] Проверить, что непрочитанные уведомления выделены фоном

## 14. Настройки профиля

- [ ] Открыть страницу `/settings`
- [ ] Проверить загрузку текущих данных пользователя
- [ ] Изменить имя и фамилию — сохранить
- [ ] Проверить, что имя обновилось в боковом меню
- [ ] Изменить должность — сохранить
- [ ] Ввести текущий пароль без нового пароля — ошибка валидации
- [ ] Ввести новый пароль без текущего — ошибка валидации
- [ ] Ввести оба пароля — смена пароля

## 15. Управление пользователями (ADMIN)

- [ ] Открыть страницу `/users` (только для ADMIN)
- [ ] Проверить отображение таблицы пользователей
- [ ] Нажать "Добавить пользователя"
- [ ] Заполнить форму и создать пользователя
- [ ] Нажать "Редактировать" — изменить роль, должность
- [ ] Удалить пользователя (нельзя удалить себя)
- [ ] Проверить, что удалённый пользователь исчез из списка

## 16. Комментарии

- [ ] Открыть задачу с комментариями
- [ ] Проверить отображение комментариев
- [ ] Написать новый комментарий — отправить
- [ ] Проверить, что комментарий появился в списке
- [ ] Удалить свой комментарий (кнопка "Удалить")
- [ ] Проверить, что ADMIN может удалить чужой комментарий

## 17. Поиск (Header)

- [ ] Ввести запрос в поле поиска в шапке
- [ ] Проверить отображение результатов (задачи, проекты, пользователи)
- [ ] Клик на результат — переход на соответствующую страницу
- [ ] Очистить поле поиска

## 18. Адаптивность (Mobile)

- [ ] Уменьшить ширину окна браузера до мобильного размера
- [ ] Проверить гамбургер-меню
- [ ] Открыть/закрыть боковое меню
- [ ] Проверить корректное отображение таблиц на мобильных
- [ ] Проверить корректное отображение Kanban доски (горизонтальная прокрутка)

## 19. Обработка ошибок

- [ ] Отключить сеть — проверить сообщения об ошибках
- [ ] Попробовать создать задачу без обязательных полей
- [ ] Попробовать создать дубликат пользователя (тот же email)
- [ ] Попробовать удалить несуществующий ресурс

## 20. Безопасность

- [ ] Проверить, что EMPLOYEE не может создавать проекты
- [ ] Проверить, что EMPLOYEE не может управлять пользователями
- [ ] Проверить, что пользователь не может модифицировать задачи в чужих проектах
- [ ] Проверить, что JWT токен истекает через 7 дней
- [ ] Проверить, что пароли хешируются (не хранятся в открытом виде)
